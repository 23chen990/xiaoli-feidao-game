# 疯狂切割 · TapTap Mini Game

This isolated Cocos Creator 3.8.8 project is the TapTap ordinary Mini Game target for game ID `928932`.
The default portrait journey uses one touch to launch/flip, sharp contact to cut, blunt contact to reflect,
hazards/falls to fail, and the finish gate to settle and replay. Geometry and presentation are original and
programmatic; this is not a browser wrapper.

The audited official `taptap-minigame-tools` 1.2.2 extension is installed under `extensions/`. A successful
Creator WeChat Mini Game build with `enableTapConvert=true`, `tapAppid=928932`, and `gameVersion=1.0.0`
must produce `build/TapBuild/game.zip`. Backend scan and physical-device testing remain independent QA gates.
