Slice Master UI组件拆解清单
一、设计原则
UI不是信息展示。
UI是爽感放大系统。
二、World UI
1. 奖励数字
触发：
切割成功
动画：
scale 0.5 -> 1.2 -> 1
向上漂浮
透明消失
位置：
跟随切割位置
2. Combo反馈
触发：
连续切割
要求：
短暂出现
不打断操作
3. 命中特效
包括：
碎片
闪光
粒子
三、Screen UI
1. HUD
原则：
极简。
避免：
任务、等级、复杂信息。
2. 失败界面
目标：
制造遗憾。
不要：
强调失败。
推荐：
差一点！
继续挑战。
3. 复活按钮
优先级：
继续挑战 > 返回
四、终点倍率UI
作用：
第二小游戏。
流程：
倍率滚动
+
等待
+
最终奖励爆发
必须包含：
- 数字变化
- 高潮动画
- 奖励强化
五、镜头UI
Camera承担：
- 注意力引导
- 危险预告
- 高潮放大
六、动画时间建议
点击反馈：
0.1秒内
命中停顿：
50-100ms
奖励数字：
0.5-1秒
结算高潮：
2-3秒
